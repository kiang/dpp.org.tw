馬政府因應景氣振興經濟十大方案的問題與批判

馬政府「因應景氣振興經濟」十大方案的問題與批判

政策會08.09.11

 

    馬政府520上台以來，相繼推出「加強地方建設，擴大內需方案」、「周末包機及大陸觀光客來台方案」、「救股市五大措施」、「刺激景氣八大措施」，但是台灣經濟卻是持續倒退嚕：股市自520以來跌超過2,800點；七、八連續兩個月入超；八月份外匯存底大幅減少88.11億美元；景氣燈號轉呈代表景氣衰退的藍燈，對策信號分數創2003年6月SARS以來最低的15分；失業率上升至4.06%；通膨處在4.78%居高不下，造成民間消費急凍。

    面對民怨的高漲以及要求改組的聲浪下，9月11日劉內閣再度緊急拼湊出包括「調降證交稅」等措施的十大「因應景氣振興經濟」方案大補帖，將過去已宣示過的政策及各部會例行業務重新包裝。不過股市當天卻大跌206點，顯示馬政府的政策反覆、沒有對症下藥、飲鴆止渴的作法，已經讓全民及外資對馬政府的財經政策喪失信心。

 

措施

問題與批判

刺激消費

一、照顧弱勢

n       當前各國幾乎都採取退稅濟貧的做法，但國民黨卻因為民進黨主張退稅濟貧而不願意接受這種最有效也照顧到最多數弱勢者的政策。為了政黨自私和馬總統的面子，國民黨竟犧牲全民的利益。

n       現在人民最痛苦的是失業找不到工作，但是這些補貼方案沒有幫助到真正失業弱勢的人，反而是去補貼有工作所得的族群，方向完全搞錯。

n       未照顧到「部分工時」的辛苦弱勢勞工，「工作所得補助方案」規定補助的對象限制在全職工作者，排除常常以打零工維生的弱勢勞工。

n       未必增加工作勤勞，此一政策意在增加工作誘因，提高勞動意願。事實可能是，既然政府有補貼，那麼可以選擇增加休閒時間，何樂而不為？甚至謊報工作所得，增加補助。

(一)推動「工作所得補助方案」

(二)加速落實「當前物價穩定方案」中照顧弱勢補貼措施

二、鼓勵消費

n       拿「節能環保」的既有政策來充數。這部份所增加的消費效果僅是杯水車薪，無法有效解決當前停滯性通貨膨脹所造成的全面性民間消費急凍的問題。

n       當初設定國民旅遊卡必須異地隔夜消費限制的目的，就是在鼓勵消費，現在放寬此限制，讓公務員可拿日常的消費來領旅遊津貼，反而是在降低消費，變相淪為成為公務員的額外薪水。

(一)補助購置節能燈具（泡）、太陽能熱水系統、太陽光電系統，及符合節能標章之冷氣機、電冰箱、洗衣機等家庭用節能減碳產品。

(二)放寬國民旅遊卡使用限制

(三)推廣具節能效益之LED燈具（泡）（交通號誌燈、出口指示燈、避難方向指示燈、消防指示燈等），納入政府共同供應契約，並鼓勵民間採購。

(四)補助民眾購買使用電動機車及低污染車，以及汰換老舊車輛。

三、促進就業

n       大多是青輔會及勞委會的經常性業務或小型訓練專案拿進來包裝，欠缺創新的產業方向所帶動的大量就業效果。

n       第四項措施的實施期間為(97.1-97.12)，為延續民進黨執政時的既有政策，並非馬政府針對提振當前景氣所推出的新措施。(本方案41項措施中有15項屬於這類情況)

n       第五項措施所列的具體做法僅停留在研擬「地方產業發展方案」階段，流於空泛敷衍應付、無具體目標設定及時程管控。

(一)放寬「雇主僱用失業勞工獎助辦法」

(二)協助青年就業

(三)辦理具有提升生活品質或促進社會公益之臨時性專案計畫，提供2,500名臨時工作機會。

(四)補助企業訓練員工費用，鼓勵企業投資員工訓練。

(五)發展地方產業，促進地區性就業。

振興投資加強建設

四、優惠房貸

n       問題的重點在於房價太貴，一般人民根本買不起房子，繳不起頭期款。

n       政府低利貸款，將鼓勵更多還款能力較低的民眾購屋，當利率上升或兩年期滿要開始付息時，必將有不少人無力還款付息。這種利率先低後高吸引還款能力較低者之房貸，極似美國次級房貸的翻版。一旦這些購屋者不願或無力承擔損失而中止償還貸款，銀行就會出現鉅額的呆帳。

n       當房價和景氣若持續下滑，則現在因為政府房貸政策而購置房屋的人就會蒙受巨大損失。政府政策把原本該由建商承擔的跌價損失，移轉成購屋者的損失，顯然不公平。

(一)增撥新台幣2千億元優惠購屋專案貸款

(二)推動青年安心成家方案

(三)持續提供購置住宅貸款利息補貼(含弱勢戶及一般戶)

(四)持續提供修繕住宅貸款利息補貼(含弱勢戶及一般戶)

(五)對無力購置住宅者，由中央政府提供租金補貼。

五、加強公共建設

n       積極鼓勵民間參與公共建設及都市更新措施，無具體目標、經費預算及時程管考，流於既定政策口號的陳述。

n       推動陸資來台投資公共建設，將跟國內的營造業搶時大餅，並增加日後營運維護上的風險

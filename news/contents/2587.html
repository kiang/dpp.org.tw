九劉政府，八大『錯』施

 

─當前經濟情勢及馬政府「八大刺激景氣措施」分析

 

（2008.09.03）

 

前言

馬政府上台百日以來，財經政策混亂，提不出新的發展方向，不僅放任油、電、肥料價格暴漲，更吹噓股市房市會大漲，並且過度期待對中國開放所帶來的經濟效益。全球停滯性通膨衝擊，再加上馬政府對經濟的治理無方，台灣經濟不諦是雪上加霜。主計處剛公佈的下半年經濟成長已明顯走緩，7月份國內經濟指標更是全面轉壞，物價大幅上升近6%，失業率突破4%，對外貿易由出超變成入超4.1億美元，股市房市價跌量縮、景氣燈號轉為衰退的藍燈並創下2003年6月SARS以來最低15分。

面對「內外皆冷」的經濟情勢，馬政府所提出的「八大刺激景氣措施」，不但方向完全搞錯，沒有照顧到最痛苦的失業弱勢族群，更是在重製國民黨九O年代的泡沫經濟政策。過去民進黨政府採取鼓勵企業走向創新「知識經濟」、帶動「兩兆雙星」新的產業方向，但是馬政府採取的是傳統、數量的政策思維，用減稅、補貼的方式，鼓勵現有企業擴大投資加碼。惟在市場萎縮、設備閒置、企業沒有利潤的情況下，這些降價的措施都沒有效果。

馬政府這些停留在九O年代舊思維的財經官員，面對二十一世紀新的經濟情勢挑戰，提出來的都是舊工具的空包彈，難怪馬英九只能硬坳說「希望在2016年達到633目標」，以逃避人民對馬政府跳票的失望與責難。

 

 

一、2008年下半年經濟情勢「內外皆冷」

1.          2008年下半年經濟成長明顯走緩：依據主計處最新預測，2008年下半年經濟成長率降為3.4%。(政黨輪替前民進黨政府2008年第I季的經濟成長率為6.25%)

2.          2008年7月國內經濟指標全面轉壞：

n          核心物價漲幅擴大，消費者物價(年增率5.92%)及躉售物價(年增率11.49%)均大幅上升，遠遠超過3%的通膨警戒線。

n          失業率由3.95%上升至4.06%，大學以上學歷的失業率為5.03%，15~24歲的年輕人失業率更高達12.73%。

n          出口和外銷訂單成長大幅減緩，對外貿易由出超轉為入超4.1億美元。

n          工業生產成長由過去民進黨執政時期的平均兩位數成長，萎縮至年增率僅1.1%。

n          金融市場動盪，股市價跌量縮，自520馬政府上台以來已跌約2,600點，新台幣兌美元匯率貶值，也代表外資撤離對台灣經濟失去信心。

n          核發建照面積減少28.8%。

n          零售業及汽車業銷售率下滑，內需市場大幅萎縮。

n          課稅收入減少，較去年同期減少27.6%。

n          景氣領先指標與同時指標雙雙下滑，景氣對策信號分數降為15分，燈號由黃藍燈轉呈代表景氣衰退的藍燈，創2003年6月SARS以來最低分。

二、景氣變壞的原因

1.    盲目讓物價飆漲：放任油、電、肥料價格暴漲，牽動百業物價上漲，人民花同樣的錢可以買到的東西變少，造成需求減少，支出減少。

2.    把泡沫吹破：馬政府吹噓股市房市會大漲，結果把牛皮吹破了。「中國炒樓團」炒作失敗後台灣房市就跌下來；股價二萬點上不去後也造成暴跌結果。

3.    政策混亂、父子騎驢：造成投資者沒有信心，投資自然減少。

4.    提不出新的產業大方向：過去民進黨執政時期提出「知識經濟」、「兩兆雙星」等產業發展大方向，但是新的經濟部長認為「兩兆雙星」沒有意義，方向不見了但又提不出新的方向。

5.    採傳統、數量的政策方式：民進黨政府採取鼓勵企業走向知識經濟、走出新的產業，但是馬政府採取的是傳統、數量的政策思維，用減稅、補貼、降價方式，鼓勵業者做更大。惟在市場萎縮、設備閒置情況下，包括這些「刺激景氣八大措施」都是沒有用的。

6.    只講對中國開放：馬政府一直以為對中國更開放，對台灣的投資就會更增加。結果是除了少數台商會回來台灣之外，卻有更多的台灣企業等著去中國投資。

三、馬政府「八大刺激景氣措施」的問題與批判

項目

問題與批判

備註

一、 實施短期企業投資租稅優惠措施：凡製造業及相關技術服務業於97年7月至98年底新增重大投資得比照「促進產業升級條例」相關規定辦理。

● 本措施與促進產業升級條例將落日的政策背道而馳。

● 重大政策要有財源，財源在哪裡？會排擠什麼支出？韓國6月宣布企業減稅，現在已決定調整延後一年，以挪出財源來濟貧。

● 要求減免部分只能限於投資企業「五年免稅」，不應適用「股東投資抵減」，因為「五年免稅」屬公司減稅，最後有分配到盈餘的股東還是要繳稅；「股東投資抵減」則會讓富人得利，並延伸到其他獲利產業。

● 這項措施沒有針對有效的投資來獎勵，應要求增加條件門檻。包括該投資案必須增加多少本國勞工就業機會，才能享有五年免稅優惠，否則將會造成資本密集產業得到最大好處，卻對就業機會的創造貢獻不大。相對地，新加坡就是以創造就業為主要目標。

● 民進黨當年提倡「知識經濟」和「兩兆雙星」產業，有明確方向，故政策會有效。現在人們對政府沒信心，產業發展沒方向，沒利潤，設備過剩，獎勵企業擴大投資也沒效果。效果即使有，也可能造成投資過剩，這是舊思維東施效顰的做法。

● 依據促進產業升級條例第72條規定，租稅減免部分施行至98年底。

● 行政院規劃，投資租稅優惠措施內容包括可享受「五年免稅」或「股東投資抵減」。

二、 擴大建築及房屋貸款餘額，由經建會協調相關部會放寬或提高有關建築及房屋貸款餘額比例上限(30%)。

● 30%上限是為了金融穩定的思考，而國民黨這項措施是在重製九O年代的泡沫經濟政策。我國在九O年代泡沫經濟時也是對不動產大量放款，1997年東亞金融風暴後又對許多企業延長或擴大放款以紓困，結果造成近兩兆的呆帳。若非民進黨政府金融重建基金和「一次金改」對金融業注入大量資金，台灣可能在2002年前後即已爆發嚴重的金融危機。目前的執政黨在1990年代錯誤的放款政策造成了泡沫經濟和後來的鉅額呆帳，但因2000年的政黨輪替而不必自己承擔和處理其後果，現在又要重新製造泡沫。

● 當房價和景氣若如預期繼續下滑，則現在因為政府双貸政策而購置房屋的人就會蒙受巨大損失。政府政策把原本該由建商承擔的跌價損失，移轉成購屋者的損失，顯然不公平。

● 目前建築及房屋貸款餘額比例約在21%，沒有提高比例上限的急迫性，當前主要的問題在於銀行不敢貸款。因此很多人懷疑這項政策是不是在支援某些特定瀕臨財務危機的營建業者。

銀行法第72-2條規定商業銀行辦理住宅建築及企業建築放款之總額，不得超過放款時所收存款總餘額及金融債券發售額之和之百分之三十。但下列情形不在此限：

一、為鼓勵儲蓄協助購置自用住宅，經主管機關核准辦理之購屋儲蓄放款。

二、以中央銀行提撥之郵政儲金轉存款辦理之購屋放款。

三、以行政院經濟建設委員會中長期資金辦理之輔助人民自購住宅放款。

四、以行政院開發基金管理委員會及行政院經濟建設委員會中長期資金辦理之企業建築放款。

五、受託代辦之獎勵投資興建國宅放款、國民住宅放款及輔助公教人員購置自用住宅放款。

主管機關於必要時，得規定銀行辦理前項但書放款之最高額度。

● 由於修法難度高，馬政府可能不透過修法，而是採行以上述五項政策性房貸方式處理。

三、 提高優惠利率補貼，有效實施現行房貸方案。

● 行政院沒有提出明確的財務計畫，包括補貼多少？錢從哪裡來？補貼期間與對象為何？

● 政府低利貸款，將鼓勵更多還款能力較低的民眾購屋，當利率上升或兩年期滿要開始付息時，必將有不少人無力還款付息。這種利率先低後高吸引還款能力較低者之房貸，極似美國次級房貸的翻版。一旦這些購屋者不願或無力承擔損失而中止償還貸款，銀行就會出現鉅額的呆帳。

現行購置住宅優惠措施

● 貸款額度最高220萬元，償還年限最長20年

● 優惠利率：經主管機關認定符合弱勢條件者，郵儲利率減0.533%。其餘對象，郵儲利率加0.042%。

四、 自9月1日開始推動「工作所得補助方案」，將投入135億元，照顧約45萬戶近貧家庭。

● 依照各國的做法，大家幾乎都在退稅濟貧，但國民黨卻因民進黨主張退稅濟貧而不願意接受這種最有效也最照顧多數弱勢者的政策。為了政黨自私和馬總統的面子，國民黨竟犧牲全民利益。

● 現在人民最痛苦的是失業找不到工作，但是這項補貼方案無法幫助到那些失業貧窮的人，方向完全搞錯。

● 未照顧到「部分工時」的辛苦弱勢勞工。此方案第2項條件要求在95年時月所得必須要達15,840元，才能達到補助門檻，但就以時薪90元的部分工時者，必須每天工作8小時，一年工作264天以上，幾乎都達不到。

● 第2項條件對於現在有工作，但是95年沒有工作的勞工不能請領補助，是不公平的事。方案應著重在鼓勵不想工作的人出來工作，不應對找到工作之前的情況設定條件門檻。

● 目前由於資本利得不用課稅、地下經濟課不到稅，及真正的窮人繳不起稅，若是實施以所得稅作為基礎的補助，可能造成所得分配更不平均。

行政院方案

（一）實施對象是針對年滿20歲至未滿65歲國民，為全戶主要收入者，其個人年薪資在新台幣30萬元以下，並且符合以下各項條件：

（1）非低收入戶；

（2）為全職工作者（97年1月至6月參加勞工保險或就業保險，且95年全年薪資超過19萬80元）；（3）申請人配偶或所扶養未滿65歲之ㄧ親等親屬年薪資所得均在30萬元以下；

（4）申請人及其配偶或扶養未滿65歲之ㄧ親等親屬合計最近一年度綜合所得未超過基本門檻（單身無配偶或親屬者在25萬元以下；有配偶或扶養一親等親屬者除綜合所得總額30萬元外，每增加親屬1人以10萬元加計）；

（5）申請人及其配偶或扶養未滿65歲之一親等親所有不動產價值合計未超過390萬元。

（二）內政部指出，本方案之補助金額是按照申請人與配偶二人全年平均薪資進行分級，每月補助額度分為3,000至6,000元共五級。

五、 中央主管機關積極協助地方政府加速落實「加強地方建設擴大內需方案」，並有效管考，提升執行成效。

● 空包彈，屬於經常性業務既定政策。

● 要求提出更有力的政策作法。

 

六、 加速落實「當前物價穩定方案」中照顧弱勢補貼措施（低收入戶生活補助、弱勢團體健保補助、弱勢族群國中小學生營養午餐、馬上關懷專案等），並有效管考。

● 社會救助有淪為村里長綁樁之嫌，嚴重破壞社會救助的申請、審核、認定、給付體系，將使社會救助與社會工作脫離，社會工作專業無用武之地。

● 將陷村里長、鄉鎮市公所、民間團體於圖利他人、得罪村民、違法濫權的困境。

行政院方案

本專案對於遭逢急難民眾本人或親人、學校等相關機關均可向村（里）辦公處、鄉鎮市公所、縣政府申請，對於申請急難救助個案亦直接由鄉鎮市公所及村里長或村里幹事及民間慈善團體社工人員進行通報與審核認定，將使政府照顧弱勢族群政策具體落實並實際受惠於各村里角落之急難民眾。馬上關懷專案規定，九十七年所需經費以每一村里每月核發關懷救助金一件、每件平均兩萬元，以及行政事務費每件兩百元計算，預撥地方政府。

七、 擴大招商：經濟部、金管會、交通部等主管機關訂定行動方案，擴大國際招商。

● 空包彈， 屬經常性業務。政府必須提出實質的政策措施，改善競爭力，創造更優質的投資環境，才能吸引外商。

 

八、 由經濟部積極督導重大投資案落實執行。

● 空包彈，屬於經常性業務。
